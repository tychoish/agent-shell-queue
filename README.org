* Overview
A persistent prompt queue for [[https://github.com/xenodium/agent-shell][agent-shell]] sessions, supporting multi-session
dispatch with pause, resume, and archive lifecycle management.  Queue state is
serialized to plist, JSON, or YAML for session persistence across Emacs
restarts.  Interactive capture, edit, and item-view buffers allow queue
manipulation without leaving Emacs.  Fork operations split a queue across
multiple sessions for parallel workloads.

This repository also includes ~agent-shell-menu.el~: ACR-based transient menus
for navigating and controlling agent sessions, covering permission resolution,
action selection, command insertion, and collapse control.  The menu requires
the queue and can be loaded separately with ~(require 'agent-shell-menu)~.

* Installation
** package-vc

Requires Emacs 29.1+.  Run once to clone and register the package:

#+BEGIN_SRC emacs-lisp
(package-vc-install '(agent-shell-queue
                      :url "https://github.com/tychoish/agent-shell-queue"))
#+END_SRC

** use-package with VC

Requires Emacs 30+.  Installs on first load if not already present:

#+BEGIN_SRC emacs-lisp
(use-package agent-shell-queue
  :vc (:url "https://github.com/tychoish/agent-shell-queue")
  :after agent-shell)
#+END_SRC

** ELPAish Snapshot Repository

agent-shell-queue is also published as a development snapshot on
[[https://github.com/tychoish/elpaish][ELPAish]], a self-hosted, GPG-signed
Emacs Lisp package archive.  Add the snapshot stream to
~package-archives~ and install normally with =package-install=:

#+BEGIN_SRC emacs-lisp
(add-to-list 'package-archives
             '("elpaish" . "https://tychoish.github.io/elpaish/snapshot/") t)
(package-refresh-contents)
(package-install 'agent-shell-queue)
#+END_SRC

To verify package signatures, import the ELPAish signing key into
=package.el='s keyring and enable signature checking:

#+BEGIN_SRC emacs-lisp
(url-copy-file "https://tychoish.github.io/elpaish/elpaish-keyring.gpg"
               "elpaish-keyring.gpg" t)
(package-import-keyring "elpaish-keyring.gpg")
(setq package-check-signature t)
#+END_SRC
