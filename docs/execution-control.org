#+TITLE: Execution Control

* Features

- *Global and Per-Session Pausing*: Suspend dispatch globally (via [[file:api.org::#agent-shell-queue-pause][~agent-shell-queue-pause~]]) or for an
  individual session (via [[file:api.org::#agent-shell-queue-session-pause][~agent-shell-queue-session-pause~]]); active tasks finish while queued tasks hold.

- *Flow Modifiers and Checkpoints*: Insert pause checkpoints (via [[file:api.org::#agent-shell-queue-insert-pause][~agent-shell-queue-insert-pause~]]), context wipes (via [[file:api.org::#agent-shell-queue-insert-clear-context][~agent-shell-queue-insert-clear-context~]]), or
  wait-until timers (via [[file:api.org::#agent-shell-queue-insert-wait][~agent-shell-queue-insert-wait~]]) anywhere in the queue order.

- *Automated Recovery*: Recover stuck ACP/shell-maker processes (via [[file:api.org::#agent-shell-queue-recover-stuck-shell][~agent-shell-queue-recover-stuck-shell~]]) by interrupting
  and auto-resuming once idle.

- *Pre and Post Turn Delays*: Regulate rate limits with configurable pauses between consecutive turns (via [[file:api.org::#agent-shell-queue-default-pause-delay][~agent-shell-queue-default-pause-delay~]]).

* Key Functions

- [[file:api.org::#agent-shell-queue-pause][~agent-shell-queue-pause~]] / [[file:api.org::#agent-shell-queue-resume][~agent-shell-queue-resume~]]: Toggle queue dispatch
  globally.
- [[file:api.org::#agent-shell-queue-session-pause][~agent-shell-queue-session-pause~]] / [[file:api.org::#agent-shell-queue-session-resume][~agent-shell-queue-session-resume~]]:
  Control dispatch for a single session.
- [[file:api.org::#agent-shell-queue-insert-pause][~agent-shell-queue-insert-pause~]]: Insert an auto-resuming or manual pause
  item.
- [[file:api.org::#agent-shell-queue-insert-clear-context][~agent-shell-queue-insert-clear-context~]]: Insert a context-wipe boundary item.
- [[file:api.org::#agent-shell-queue-insert-wait][~agent-shell-queue-insert-wait~]]: Block queue until a specified date/time.
- [[file:api.org::#agent-shell-queue-recover-stuck-shell][~agent-shell-queue-recover-stuck-shell~]]: Interrupt a wedged shell and resume
  when idle.

* Example

#+BEGIN_SRC emacs-lisp
  ;; Insert a 30-second pause checkpoint into the active shell queue
  (agent-shell-queue-insert-pause (current-buffer) nil 30.0)

  ;; Insert a scheduled wait timer
  (agent-shell-queue-insert-wait
   (current-buffer))
#+END_SRC
