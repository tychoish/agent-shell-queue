#+TITLE: Task Interjection and Queue Inspection

* Features

- *Live Turn Interjection*: Interrupt a running agent turn to inject urgent instructions, automatically appending continuation prompts.

- *Tabular Queue Management*: Review, reorder, defer, assign, or delete items in the ~*agent-shell-queue*~ overview.

- *Popup and Direct YAML Editing*: Edit single prompts in markdown popups or bulk-edit queue structure in raw YAML.

- *Inspect Raw Serialization*: View item representations in plist, JSON, or YAML format.

* Key Functions

- ~agent-shell-queue-interject~: Interrupt running item and open an interjection capture buffer.
- ~agent-shell-queue-buffer-open~ / ~agent-shell-queue-buffer-switch~: Open/switch to queue overview.
- ~agent-shell-queue-edit-task~: Interactively edit a queued prompt.
- ~agent-shell-queue-raw-edit~: Bulk-edit entire queue state in YAML.
- ~agent-shell-queue-buffer-inspect-item~: Inspect serialized item representation.

* Example

#+BEGIN_SRC emacs-lisp
  ;; Interject the current running agent task
  (agent-shell-queue-interject)
#+END_SRC
